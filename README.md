# NANATATA · 个人网站

个人介绍与项目作品。<https://yzh2006517.github.io/>

两个 Windows 桌面软件各配了一块可以直接上手的网页演示：

- **AI 虚拟主播** — 发一条弹幕，看它走完「弹幕 → 大模型 → 语音+动作 → 直播画面」，
  也可以切到弹幕小游戏模式答题计分。
- **Photo All Studio** — 拖动胶卷和折射放大镜，切换背光与胶片风格。

演示只在网页里模拟，不连真实模型。软件本体见
